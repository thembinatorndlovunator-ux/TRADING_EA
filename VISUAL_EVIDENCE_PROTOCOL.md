# VISUAL EVIDENCE PROTOCOL

For every reviewed trade, link:

- Trade ID
- Before-entry screenshot
- Entry screenshot
- Exit screenshot
- Annotated copy
- EA version
- Git commit
- Set file
- Journal row
- Trade-history row
- Symbol and timeframe
- Broker/server time
- News context

Analysis report:

1. Objective visual observations.
2. EA decision confirmed by journal.
3. Regime.
4. Strategy.
5. Candlestick pattern.
6. Chart pattern.
7. Entry assessment.
8. Stop assessment.
9. Exit assessment.
10. Profit-giveback assessment.
11. Certain findings.
12. Hypotheses.
13. Missing evidence.
14. Proposed test.

Never change code because of one screenshot.
